# MATLAB Code for the George B. Moody PhysioNet Challenge 2025

## What's in this repository?

This repository contains the MATLAB implementation for the George B. Moody PhysioNet Challenge 2025 prepared by Team Spectra.

The code can be used to:

* train the model on the Challenge data;
* run the trained model on holdout data; and
* generate the model outputs required for evaluation.

The main MATLAB scripts are:

* `train_model.m` — used to train the model.
* `run_model.m` — used to run the trained model and generate outputs.

The evaluation code is **not included in this repository**. The generated model outputs are evaluated separately using the official Challenge evaluation procedure.

## Requirements

To run the code directly, you need:

* MATLAB;
* the Challenge data.

The Challenge data should be prepared according to the instructions provided with the 2025 Challenge.

## How do I run these scripts?

### Training

Open MATLAB and navigate to the root directory of the repository.

Run:

```matlab
train_model(training_data, model)
```

where:

* `training_data` is a folder containing the Challenge training data, including the labels; and
* `model` is a folder where the trained model will be saved.

For example:

```matlab
train_model('training_data', 'model')
```

### Inference

After training the model, run:

```matlab
run_model(holdout_data, model, holdout_outputs)
```

where:

* `holdout_data` is a folder containing the holdout data;
* `model` is the folder containing the trained model; and
* `holdout_outputs` is the folder where the model outputs will be saved.

For example:

```matlab
run_model('holdout_data', 'model', 'holdout_outputs')
```

The generated files in `holdout_outputs` are used for evaluation.

**The evaluation code is not included in this repository.**

Evaluation is performed separately using the official Challenge evaluation code.

## Evaluation

The official evaluation code is available in the separate 2025 evaluation repository:

https://github.com/physionetchallenges/evaluation-2025

The evaluation procedure takes:

* the labels for the holdout data;
* the model outputs generated by `run_model`; and
* an optional output file containing the evaluation scores.

The official MATLAB example describes the evaluation interface as:

```text
evaluate_model(labels, holdout_outputs, scores.csv)
```

The evaluation code is separate from this repository and should be obtained from the official evaluation repository.
